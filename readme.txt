Plugin gratuito de Kairoseth para solicitar valoraciones, recoger feedback y gestionar una o múltiples sedes desde WordPress.

== Description ==

Reseñas WordPress permite crear un flujo de valoración post-servicio dentro de WordPress.

El caso de uso recomendado es enviar al cliente un enlace por WhatsApp después de una compra, servicio, reserva, cita o intervención. También puede utilizarse desde web, email, SMS, QR u otros canales.

Funciones principales:

* Valoraciones de 1 a 5 estrellas.
* Feedback interno.
* Enlaces a Google Reviews.
* Una o múltiples sedes.
* Google Review URL independiente por sede.
* Referencias externas mediante `?ref=`.
* Selección de sede mediante `?sede=`.
* Registro del origen de la valoración.
* Personalización de logo, colores y textos.
* Avisos por email.
* Datos almacenados localmente en WordPress.

Shortcode principal:

`[resenas_wordpress]`

== Installation ==

1. Sube el ZIP del plugin desde Plugins > Añadir plugin > Subir plugin.
2. Activa Reseñas WordPress.
3. Configura la marca y las sedes desde el menú Reseñas WordPress.
4. Inserta `[resenas_wordpress]` en una página.
5. Comparte la URL de esa página con tus clientes.
